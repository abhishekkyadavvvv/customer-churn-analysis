# Customer Churn Analysis

## Overview
This project analyzes customer churn data using Python, Pandas, and SQLite.

## Tools Used
- Python
- Pandas
- NumPy
- SQLite
- Matplotlib

## Key Analysis
- Churn by State
- Churn by Plan Type
- Revenue Impact
- Customer Tenure Analysis
- Escalation Trends

## Skills Demonstrated
- Data Cleaning

- Exploratory Data Analysis
- Data Visualization
- Business Insights
